A Flutter mobile application for Astroway customers.

\-\--

\## 🚀 Environment Requirements

Make sure the following versions are installed to run and build the app:

\- \*\*Flutter SDK\*\*: 3.24.3 - \*\*Dart SDK\*\*: 3.5.3 - \*\*Kotlin

Studio or VS Code\*\* with Flutter & Dart plugins
